# Skills

Kronos ships a curated engineering skill set under `skills/core/` with regression prompts in `skills/regression/`. Skill count is not a quality metric.

## Core categories

Repository inspection, planning, TDD, debugging, code review, security review, Git/GitHub, dependency changes, migrations, frontend and backend testing, accessibility, documentation, research/citations, and skill regression.

## Import

Community Agent Skills packs may be imported through an explicit workflow:

1. Fetch an immutable revision.
2. Scan included scripts and assets.
3. Display declared capabilities and files.
4. Install into quarantine.
5. Run regression prompts and permission checks.
6. Activate only after approval.

Imported skills stay quarantined until a human approves. Harmful outcomes roll implicated skills back.

## Lessons

Readable text with provenance and helpful/harmful counters is authoritative. Propose is not activate. prior `lessons.yaml` imports as `disabled_candidate` records. See `examples/removed/lessons.yaml`.
